# Data Preparation

This directory documents the expected data schema and provides a synthetic data generator so the rest of this repository can be run end-to-end without access to the real (access-controlled) UK Biobank data.

## Files

- **`SCHEMA.md`** — The full column-by-column schema every script in this repository expects (recovered from the original preprocessing notebooks), plus the derived columns computed at runtime (`label`, standardized `PRS`, `icd10_sequence` text) and the train/val/test split conventions used across the GNN vs. BERT pipelines.
- **`icd10_blocks.py`** — The list of ICD-10 block descriptions (`ICD10_BLOCKS`) used as diagnosis columns, e.g. `"Hypertensive diseases"`, `"Arthropathies"`.
- **`generate_synthetic_data.py`** — Fabricates a CSV matching `SCHEMA.md` exactly: fake patient IDs, a roughly balanced Dementia/Control split (matching the real cohort's near-50/50 split reported in the paper), ages drawn from the real cohort's reported per-class medians (Table A1), a synthetic PRS with a small mean shift for the Dementia class (so downstream models have *some* signal to chew on, purely for smoke-testing), and per-ICD-10-block presence/time-since-diagnosis columns with a slightly higher diagnosis burden for the Dementia class.
- **`five_updated_synthetic.csv`** — A synthetic dataset already generated by this script (2000 patients), used by the other modules' smoke tests.

## Usage

```bash
python generate_synthetic_data.py --n-patients 2000 --out five_updated_synthetic.csv --seed 42
```

## Important caveat

**This data is entirely fake.** It is not derived from, and does not resemble, any real individual's data. Every number (ages, PRS, diagnosis rates) is drawn from a simple parametric distribution loosely anchored to summary statistics reported in the paper (e.g. Table A1 age medians, the ~50/50 class balance), purely so the shape and column names match the real schema. Model performance measured on this synthetic data is **structurally valid but meaningless** — it proves the code runs end-to-end, not that it reproduces the paper's results. To reproduce the paper's actual Table 1 numbers, a real UK Biobank extract matching this schema is required (access-controlled under application 109607 — see the top-level README for details on this restriction).

## Consumers

Every other module in this package (`baselines/`, `bert_models/`, `gnn/`, `risk_stratification/`) reads a CSV in this schema via `--data-path`, defaulting to `five_updated_synthetic.csv` where a synthetic smoke test is supported.
